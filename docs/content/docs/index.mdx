tmux-ide is a mouse-friendly terminal application around ordinary tmux
sessions. It shows your coding agents across local and SSH machines, tells you
which ones are working or need you, and lets you drive the live session with
clickable windows, pane headers and direct controls. tmux stays the authority
for processes, PTYs, layout, persistence and SSH.

```bash
curl -fsSL https://tmux-ide.com/install.sh | sh
tmux-ide app
```

## What ships in 2.9

The app has two root surfaces:

| Surface              | What it does                                                                                         |
| -------------------- | ---------------------------------------------------------------------------------------------------- |
| **Home** (`F1`)      | Agents across your machines with search, a machine filter, and All / Working / Needs attention views |
| **Terminals** (`F2`) | The selected tmux session, mirrored live with window tabs, pane headers and agent state              |

Around them:

- **Commands** (`F5`) — new windows and agents, splits, zoom, appearance, help.
- **Sessions** (`F6`) and **Attention** (`F7`) — switch sessions across machines.
- **Sidebar** (`F10`) — machines, sessions and agents; add SSH machines.
- Mouse and keyboard control for focus, splitting, resizing, renaming and
  confirmed closing — all real tmux operations, not a parallel layout model.

See [App surfaces](/docs/app-surfaces) for the full tour and
[Getting started](/docs/getting-started) for every key.

## Why tmux stays underneath

tmux has years of coverage for shells, terminal modes, resizes, detach/attach,
disconnects and SSH. tmux-ide does not replace it:

| Layer  | Owns                                              |
| ------ | ------------------------------------------------- |
| tmux   | PTYs, processes, windows and panes, persistence   |
| daemon | Discovery, lifecycle, agent state, pane streams   |
| app    | Home, Terminals, chrome, mouse and keyboard input |

If the app or daemon stops, your sessions remain ordinary tmux sessions.

## Also in the box

  Code hooks or any agent's self-report, with a transparent fallback.

## Not in this release

Files, Diff, Missions and Activity views exist in the source tree but are not
part of the 2.9 app. Mission profiles in `workspace.yml` are validated but not
run, and `tmux-ide web` is unavailable.
