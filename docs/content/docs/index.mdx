tmux-ide is an open-source terminal app for running coding agents such as
Claude Code and Codex in ordinary tmux sessions. Home shows every agent across
your local and SSH machines and which ones are working or need you. Terminals
lets you drive the live session with the mouse and keyboard. tmux stays the
authority for processes, PTYs, layout, persistence and SSH.

```bash
curl -fsSL https://tmux-ide.com/install.sh | sh
tmux-ide app
```

It runs on macOS and glibc Linux (use WSL on Windows). The installer bundles
tmux 3.7c and a private Node.js runtime and needs no sudo. Full requirements are
in [Getting started](/docs/getting-started#requirements).

## What ships in 2.9

The app has two main views:

| View                 | What it does                                                                                         |
| -------------------- | ---------------------------------------------------------------------------------------------------- |
| **Home** (`F1`)      | Agents across your machines with search, a machine filter, and All / Working / Needs attention views |
| **Terminals** (`F2`) | The selected tmux session, mirrored live with window tabs, pane headers and agent state              |

Around them:

- **Commands** (`F5`) — new windows and agents, splits, zoom, appearance, help.
- **Sessions** (`F6`) and **Attention** (`F7`) — switch sessions across machines.
- **Sidebar** (`F10`) — machines, sessions and agents; add SSH machines.
- Mouse and keyboard control for focus, splitting, resizing, renaming and
  confirmed closing — all real tmux operations, not a parallel layout model.

See [App tour](/docs/app-surfaces) for the full tour and
[Getting started](/docs/getting-started) for every key.

## Why tmux-ide is built on tmux

tmux has years of coverage for shells, terminal modes, resizes, detach/attach,
disconnects and SSH. tmux-ide does not replace it:

| Layer  | Owns                                              |
| ------ | ------------------------------------------------- |
| tmux   | PTYs, processes, windows and panes, persistence   |
| daemon | Discovery, lifecycle, agent state, pane streams   |
| app    | Home, Terminals, chrome, mouse and keyboard input |

If the app or daemon stops, your sessions remain ordinary tmux sessions.

## What else tmux-ide does

- [Agent detection](/docs/agent-detection) — ground-truth status from Claude
  Code hooks or any agent's self-report, with a transparent fallback.
- [Agent automation](/docs/automation) and [multi-agent teams](/docs/multi-agent-teams)
  — send, wait and read from the CLI, with scoped reads and sends over MCP and
  the SDK.
- [tmux chrome](/docs/the-dock) — `tmux-ide adopt` adds a status bar, keys and
  notifications to sessions you use from a plain tmux client.
- [Restore after a tmux crash](/docs/restore-resume) and
  [run agents on parallel git worktrees](/docs/worktrees).
- [Remote machines over SSH](/docs/remote-machines) — run agents on other
  machines and drive them from your app.
- [CLI reference](/docs/commands) — every command, most with `--json` output.
- [Workspace layouts and config](/docs/configuration) — the optional
  `.tmux-ide/workspace.yml` and global settings.
- [Themes](/docs/theming) — 22 presets and automatic contrast.

## Not in this release

Files, Diff, Missions and Activity views exist in the source tree but are not
part of the 2.9 app. Mission profiles in `workspace.yml` are validated but not
run, and `tmux-ide web` is unavailable.
