`2.9.17` is about slow connections and daemon responsiveness.

## Updates work on slow connections

`tmux-ide update` could fail with "Could not download the tmux-ide app runtime"
on any connection below about 1 MB/s. The 28.7 MB runtime had 30 s for the whole
transfer, and the error blamed the release.

- A download now aborts only after 30 s with no data. A slow one keeps going.
- The manifest, the runtime and all retries share a 15-minute budget.
- Timeouts, network errors and HTTP 408, 429 and 5xx responses are retried, up to
  3 attempts per file. Each retry restarts the file. A missing asset or a checksum
  mismatch is not retried.
- A stall or network error now points at your connection and the retry command.
- A second update that waits behind a running download says so.

`install.sh` had the same kind of limit: 180 s per file, while the Node.js archive
alone is over 50 MB. It now allows 900 s per file and aborts after 30 s with no data.

## The daemon answers concurrent requests

The daemon's session routes read tmux synchronously, so requests queued behind
each other. Those reads are now asynchronous, and callers that arrive while a
refresh is queued share it.

| Route                          | 8 concurrent requests vs 1, before | After |
| ------------------------------ | ---------------------------------- | ----- |
| `/api/v1/tmux-servers`         | 7×                                 | 2×    |
| `/api/resources/fleet-catalog` | 8×                                 | 2×    |

During heavy output the daemon hashes each terminal row in about 19 µs, down from
about 30 µs, with the same digests. A large flood takes about as long to finish as
before, because the daemon uses the saved time to process output more often.

## Smaller fixes

- `daemon service restart` no longer reports a daemon that the restart is shutting
  down. That race could leave a stale record in `daemon info`.
- The Mac app's browser pane applies new page state when it arrives, instead of on
  the next 16 ms tick.

Existing tmux sessions are preserved. Full list of changes:
