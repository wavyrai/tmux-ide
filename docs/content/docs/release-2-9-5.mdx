Version `2.9.5` focuses on terminal correctness and recovery. It includes the
installer and Claude Code agent-team setup from [2.9.4](/docs/release-2-9-4).

## Terminal correctness fixes

- Keep sessions with spaces in their names usable without renaming them, and prevent their discovery from blocking other sessions.

- Preserve tmux control reply ordering across pane output and drain cancelled snapshot collectors before reusing a connection.
- Preserve Unicode code points when splitting terminal paste input.
- Rebuild retained terminal surfaces after interrupted drawing so consumed damage is repainted on retry.
- Resolve bundled tmux for ordinary CLI commands when system tmux is absent from PATH.
- Retire predecessor resources after failed terminal reseeding and preserve rejected recovery-input warnings.

## Installer

Staged installation skips dependency lifecycle scripts. The supported postinstall
step runs after the verified installation has moved to its permanent location.

## Scope

These changes target terminal correctness and recovery. They do not claim full
tmux parity, zero bugs or native performance parity. Experimental native-output
completion and consumed-frame instrumentation are not included in this release.

See [2.9.4](/docs/release-2-9-4) for installer opt-out behavior and the
`tmux-ide integration agent-teams` command. The existing 2.9.4 release notes
remain available.
