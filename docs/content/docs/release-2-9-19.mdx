`2.9.19` is a CLI/daemon release. It works with native macOS alpha `0.1.14`,
which needs no update.

## Dividers on an older tmux-ide tmux

`tmux-ide update` keeps your tmux server running, so a server started before
2.9.6 keeps that release's tmux. It has some of tmux-ide's own commands, but not
the one pane dividers used, and the Mac app showed no dividers on it.

Such a server now gets dividers the same way stock tmux does since
[2.9.18](/docs/release-2-9-18): each drag is one `resize-pane` that tmux runs only
if the window's layout still matches, and the same limits apply.

`tmux-ide doctor` reports this case as:

- `older tmux-ide tmux: reduced features (restart it with tmux-ide's own tmux for every feature; that ends its sessions)`

Restarting tmux moves it to the current build only if tmux-ide starts the new
server with its own tmux. A `tmux` on your `PATH` from an older build starts the
old one again. With no server running, `tmux-ide doctor` reports the tmux that
would start next. Restarting ends every session on that server.

Update the CLI/daemon with `tmux-ide update`. Existing tmux sessions are
preserved. Full list of changes:
[CHANGELOG.md](https://github.com/wavyrai/tmux-ide/blob/main/CHANGELOG.md).
