  The 2.9.0 betas are superseded. The current release is [2.9.3](/docs/release-2-9-3); install it

</Callout>

This page keeps the highlights of the 2.9.0 beta series in the beta where each
first appeared. It is not a complete changelog, and some details changed before
the stable release — the rest of the docs describe current behavior.

## Introduced in beta.47

Pane headers and Home indicators show brief, attributed interactions while ordinary
viewer input and unknown command observations stay in activity history. CLI and
MCP callers can omit `source` to resolve their invoking pane automatically; save
the resolved intent returned with the reservation for execution and retries.
Reader names resolve across sessions. External desktop clients without a verified
tmux pane remain unidentified; external-client registration is not included.

## Introduced in beta.46

[Agent automation](/docs/automation) adds scoped CLI and MCP pane reads and sends,
operation handles, and interaction history. Native attribution is experimental,
explicitly opt-in, and off by default. Existing tmux servers are never replaced
automatically. Bundled tmux now includes its matching terminal descriptions.

This beta prioritizes Apple Silicon and Linux ARM validation. Intel Mac performance
qualification remains incomplete; Linux Intel metadata-tail latency missed the
original 50 ms target (about 55–58 ms). Spark resource tests passed their terminal
assertions but retained a process-exit observation failure; container cleanup was
confirmed. These limits do not represent new typing-latency claims.

## Introduced in beta.29

Command and theme pickers use borderless surfaces, full-width search fields, and
right-aligned shortcuts. The command menu groups actions into clear sections;
selection uses a highlight without an extra arrow. Switch session opens the same
Sessions picker as F6.

The theme picker shows alphabetical presets, marks the theme active when opened,
and previews matching themes while searching. Enter applies the choice; Escape
restores the original theme and automatic-contrast setting. Contrast remains on
by default with an off switch.

## Scroll improvements from beta.15

Native scroll optimization now activates correctly on normal TUI launches. The
resolved setting is passed directly to the native renderer before startup, so
Bun's JavaScript environment cannot leave the native default disabled. Explicit
opt-outs remain available. Ordinary and Shift-scroll preserve independent client
history positions and canonical pane geometry.

## Introduced in beta.11

- Global installation upgrades an older running daemon without stopping tmux
  sessions. App and headless launch repeat the check when install scripts were
  skipped. Use `tmux-ide update --daemon` to trigger it explicitly. Fresh installs
  leave the daemon stopped, and older clients never downgrade newer daemons.

- One TUI shows Local and multiple SSH machines in a grouped sidebar. Repeat
  `--ssh` to connect multiple hosts, or use Add machine during a run.
- Session names are scoped to their machine. Switching hosts retires the previous
  input route; a disconnected remote cannot redirect an action to Local.
- Background machines supply session metadata, while only the selected workspace
  streams terminal panes. Each remote connection reconnects independently.
- Ctrl+G focuses the machine sidebar. Use arrows to navigate and Enter to open a
  session. Agent rows still open the exact pane in the selected workspace.

See [SSH setup and limitations](/docs/remote-machines).
Saved SSH profiles can be listed, exported and imported with `tmux-ide machines`.
Remote packages must already be installed. `tmux-ide machines start <alias> --write`
explicitly starts the installed remote daemon; it does not provision a host or
install packages.

## Earlier 2.9 beta improvements

- Pane headers show recent input and pane reads, with external tmux activity
  distinguished from attributed agent activity. Failed and disconnected states
  have explicit labels.
- Appearance offers 22 theme presets alongside System, Dark, and Light.
  Open Appearance, type to filter, and use the arrow keys to preview. Enter
  saves the selection; Escape restores the previous theme. Theme changes leave
  terminal truecolor output intact.
- Resize, zoom, and retained scrollback fixes include corrected pane geometry
  and finer mouse scrolling. The TUI keeps wheel momentum in scrollback when
  returning to live output.

## Bounded during the beta

Workspace-defined Files, Diff and Missions views were part of the beta builds.
They are not part of the stable 2.9 app, which shows Home and Terminals only.
`tmux-ide web` fails with an explicit message, and mission profiles are
validated but not dispatched.

## Reporting issues

Open a [GitHub issue](https://github.com/wavyrai/tmux-ide/issues) with your OS,
architecture, tmux version, `tmux-ide doctor --json`, and the shortest
reproduction sequence.
