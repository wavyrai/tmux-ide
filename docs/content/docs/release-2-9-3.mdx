Version `2.9.3` was released on October 6, 2026. It makes remote connections,
window resizing, installation and recovery more reliable in the Home and
Terminals app. Existing tmux sessions keep running when you update or close the
app. Upgrade with `tmux-ide update`, or rerun the installer below.

## Connections and session recovery

- SSH connections recover after a remote daemon is replaced, and edits to saved
  machines apply in the running app.
- Connection errors and lifecycle logs are clearer.
- Daemon services keep their ownership through restart, interrupted updates and
  failed launcher recovery.
- Windows that a manual tmux sizing policy left out of step resize correctly
  again.
- tmux-ide refuses linked windows that two viewers would both try to control,
  and tells you to unlink them and retry.
- Agent completion stays with the right agent, and interaction observation
  reports gaps instead of silently losing events.

## Installation and updates

```bash
curl -fsSL https://tmux-ide.com/install.sh | sh
```

The managed installer supplies Node.js, bundled tmux, and the matching terminal
runtime. Updates preserve the current installation when downloads fail. Rollback
and uninstall are supported, including prefixes containing spaces. See
[Getting started](/docs/getting-started) for requirements and commands.

The published package no longer includes the retired experimental React web
client or contributor test files.

## Scope and remaining limits

Supported platforms are listed in
[Getting started](/docs/getting-started#requirements); they have not changed
since [2.9.2](/docs/release-2-9-2). This release does not claim native performance parity.
Duplicate link-event handling is fixed and covered by renderer and hosted-terminal
tests; physical terminal-emulator modifier handling remains a manual qualification
item. Native interaction observation remains experimental and opt-in.

Full list of changes: [CHANGELOG.md](https://github.com/wavyrai/tmux-ide/blob/main/CHANGELOG.md).
