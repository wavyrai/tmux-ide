# Getting started

## Requirements

- tmux 3.0 or newer; 3.2+ recommended
- Node.js 20 or newer
- macOS arm64/x64 or Linux arm64/x64

Installed releases do not require Bun. Development checkouts use Bun to build
and run the OpenTUI source.

## Install

```bash
npm install -g tmux-ide@beta
tmux-ide app
```

The first explicit app launch downloads the matching OpenTUI runtime, verifies
its metadata and SHA-256 digests, and caches it under `~/.tmux-ide/bin`.

If the download was interrupted:

```bash
tmux-ide update --tui-binary
tmux-ide app
```

## Open a session

Home lists the tmux sessions you already own. Select one with the mouse or
keyboard, or name it directly:

```bash
tmux new-session -s work
tmux-ide app work
```

If there are no sessions, press `N` on Home to create one. Closing tmux-ide does
not kill the tmux session.

## Controls

| Key          | Action                               |
| ------------ | ------------------------------------ |
| `F1`         | Home                                 |
| `F2`         | Terminals                            |
| `F5`         | Commands                             |
| `Ctrl+O`     | Cycle panes                          |
| `Ctrl+T`     | Cycle windows                        |
| `Meta+Arrow` | Resize the focused pane              |
| `Ctrl+Q`     | Quit or put away a detachable viewer |

Pane headers and window tabs also expose mouse controls for the supported
actions.

## Diagnose an install

```bash
tmux-ide doctor --json
tmux-ide inspect --json
```

When reporting an issue, include the output plus the shortest sequence that
reproduces it.
