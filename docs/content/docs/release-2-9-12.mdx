`2.9.12` adds daemon transport foundations for compatible terminal clients.
Existing clients retain their current delivery path. This release does not enable
the pending direct-Rust GUI rewrite or claim measured typing and scrolling improvements.

## Terminal delivery

Clients can negotiate binary cell and image frames, byte input, and alternate-screen
projections. A projection can defer normal-screen history; its receipt is separate
from a complete-state acknowledgement, so it cannot incorrectly advance the
client's canonical baseline. Existing complete-state clients reject unsolicited
projections.

## Local image delivery

Same-host clients can negotiate bounded, expiring image leases with inline fallback.
The daemon reuses an unchanged ownership journal when multiple leases reference
the same image, avoiding redundant disk flushes. Cleanup verifies immutable file
metadata as well as file identity, protecting replacement files when an inode is reused.

## Updating

Update the CLI and running daemon to use the new transport support. Existing tmux
sessions are preserved. The [native macOS app](/docs/native-alpha) is distributed
separately; updating the CLI does not update that app. The current native installer
retains its separately qualified CLI version.

The full direct-Rust GUI connection, its remaining live journeys, and physical
GUI performance qualification remain separate work.
